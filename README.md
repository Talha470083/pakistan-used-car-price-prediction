# Machine Learning-Based Prediction of Used Car Prices in Pakistan

## Overview

This project investigates the performance of machine learning models in predicting used car prices in Pakistan.

## Research Question

Which machine learning model predicts used car prices in Pakistan most accurately using publicly available used-car listing data?

## Objectives

1. Collect and preprocess Pakistani used-car data.
2. Identify key factors affecting car prices.
3. Train multiple machine learning models.
4. Compare model performance.
5. Determine the best-performing model.

## Models

* Linear Regression
* Random Forest
* XGBoost
* LightGBM

## Evaluation Metrics

* MAE
* RMSE
* R² Score
